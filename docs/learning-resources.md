## 第三阶段：实战项目

### 本项目（AI八字分析）核心学习点
1. **Vercel AI SDK 流式输出** — 实现打字机效果
2. **Prompt Engineering** — 设计高质量的系统提示词
3. **领域知识集成** — 将八字命理学知识融入AI
4. **前端可视化** — 五行分布图表、排盘展示
5. **全栈架构** — Next.js API Routes + 前端组件

### 推荐练手项目
- AI 翻译助手（多语言翻译 + 文化适配）
- AI 代码审查工具（Code Review）
- AI 文章摘要生成器
- AI 对话客服系统
